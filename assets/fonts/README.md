# Public website typefaces

Unmodified static TrueType releases distributed under the SIL Open Font License 1.1.
Both license notices are included in this directory. Fonts are self-hosted; the
public Coherence stylesheet does not ask the visitor's browser to contact Google.

- Newsreader Regular (400), `newsreader-regular.ttf`, by Production Type.
- DM Sans Regular (400), `dm-sans-regular.ttf`.
- DM Sans SemiBold (600), `dm-sans-semibold.ttf`.

Official distribution sources, retrieved 7 September 2026:

- https://fonts.gstatic.com/s/newsreader/v26/cY9qfjOCX1hbuyalUrK49dLac06G1ZGsZBtoBCzBDXXD9JVF438weI_ADA.ttf
- https://fonts.gstatic.com/s/dmsans/v17/rP2tp2ywxg089UriI5-g4vlH9VoD8CmcqZG40F9JadbnoEwAopxhTg.ttf
- https://fonts.gstatic.com/s/dmsans/v17/rP2tp2ywxg089UriI5-g4vlH9VoD8CmcqZG40F9JadbnoEwAfJthTg.ttf
- https://github.com/google/fonts/tree/main/ofl/newsreader
- https://github.com/google/fonts/tree/main/ofl/dmsans

CSS aliases `CN Newsreader` and `CN DM Sans` scope the family to the shared
website design without renaming or altering the font files themselves.
