When you write

Include the app or comic title, page address, device, browser or iOS version, app version if shown, what you expected, and what happened. For a comic, include the language and page number. You do not need to send private reflections, recordings, payment details or API keys. Remove personal information from screenshots before sharing them.

Features, languages and storage differ between apps and platforms. Please name the exact app and version so we can give relevant help.

Finding and reading the comics

The comic library brings together the original six issues, seven practice books, villain arcs, special stories and Insight. Choose English or Español on the library or in the reader. Use Reading size to enlarge lettering, or open the full-size image. Earlier editions remain in the original archive.

Your saved work

The website directory does not combine or move data between apps. Use each tool’s own save and export controls where available. Before clearing browser storage or reinstalling an app, export anything you wish to keep. Ask for app-specific help if you are unsure.

Common topics

  • For an eligible standalone iPhone app purchase, see Purchase help. There is no purchase to restore in Tone Sovereign V1.
  • Sota issue: name the version and the part of the practice involved. Do not include provider keys or private practice logs.
  • Audio issue: include the exact app and path, for example "Tone Recall, Love to Vessel to hold."
  • Tone Threshold issue: include the selected door, crossing mode, and whether the issue involved Return Field, Personal Chamber, audio, or Tone Plus.
  • Tone Mirror issue: include the browser, selected symbol, glyph, and whether the issue involved breath, sound, or archive replay.
  • Privacy question: email with the subject "Tone app privacy question."
  • Bug report: include steps to reproduce and screenshots or screen recordings if helpful.

Response time

Expected response time: 3 to 5 business days.
