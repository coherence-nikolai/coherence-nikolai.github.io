# Tone Sovereign Web Parity

The current iOS `ToneApp/` Golden Age catalogs are the source of truth for the web app's substantive content.

Run from this repository:

```sh
node tone_sovereign/tools/generate_catalog.mjs
```

The generator compiles the pure Swift catalog sources, applies the existing Spanish string catalog and Spanish source maps, validates canonical counts, and writes `tone_sovereign/catalog.js`.

Current validated catalog:

- 7 Fields
- 21 Laws
- 32 Principles
- 12 guided practice engines
- 69 library teachings
- 210 Sovereign Acts
- 14 Rule of Life commitments
- 10 weekly review prompts

The landing ceremony and seven-movement crossing remain purpose-built web interactions. Content routes, identifiers, teaching depth, Fields, guided practice definitions, acts, and Spanish text come from the current iOS catalogs.
